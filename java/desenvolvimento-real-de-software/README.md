### A história desse desenvolvimento é a seguinte:

O setor de FinTech está em alta e um cliente percebeu que gasta muito dinheiro em diferentes compras e seria muito útil resumir automaticamente suas despesas. Ele recebe extratos mensais de seu banco, mas os acha um tanto longos. O cliente passou a tarefa de desenvolver um software que automatize o processamento dos extratos bacários dele, para que assim ele possa ter uma visão melhor de suas finanças. 

* Nesse momento estou utilizando conceitos como "Sigle Responsability Principle" e "Keep it short and simple".
* Já foi implementando um cálculo total do quanto foi gasto e um cálculo por mês. O calculo por mês tem apenas a implementação de janeiro e fevereiro porque só tenho esses dois meses no momento no meu arquivo. É só o começo.
